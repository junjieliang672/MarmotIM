# 语音转写（听写）使用指南

按住右 Command 键说话，松开后文字直接出现在光标处。识别在**本机**完成，音频不出这台电脑。

> **这个功能是可选的。** 它默认关闭；即使你装了、又把它弄坏了，五笔拼音输入、候选词、
> 排序学习、iCloud 同步都不受任何影响 —— 输入路径上没有一次同步网络调用，也不依赖
> 语音服务是否活着。这是这个功能的验收底线，不是一句安慰话。

---

## 1. 它是什么

- 一个跑在本机 `127.0.0.1` 上的小服务（FastAPI + uvicorn），加载 MLX 版的 Qwen3-ASR 模型；
- 输入法这一侧只做三件事：录音、发一个 HTTP 请求到本机、把返回的文字按普通候选词的方式上屏。

**不联网。** 服务只监听回环地址，设置页的「主机」字段也只接受 `127.0.0.1` / `localhost` / `::1`，
填别的会被当场退回。模型权重是安装时从 Hugging Face 下载的，之后识别过程完全离线。

**不走剪贴板。** 文字通过输入法自己的上屏通道插入，不模拟 ⌘V，不动你的剪贴板。

## 2. 安装

### 2.1 一条命令

```bash
bash scripts/build_and_install.sh
```

这个脚本会构建并安装输入法，同时把语音服务也装好。只想装/修语音服务这一半：

```bash
bash scripts/install_asr.sh
```

`install_asr.sh` **不需要 sudo**（需要管理员密码的步骤都在 `build_and_install.sh` 里）。
它是幂等的：该装的都装好之后再跑一次约两秒钟就结束，什么也不会重做。

它会做这些事：

| 动作 | 落在哪 |
|---|---|
| 建 Python 3.12 虚拟环境（没有 3.12 就用 Homebrew 装一个） | `~/Library/Application Support/MarmotIM/asr/venv/`（**不在仓库里**，所以移动或删除仓库不会弄坏已装好的服务） |
| 下载模型权重（默认约 4.1 GB） | `~/.cache/huggingface/hub/` |
| 装并启动开机自启的 LaunchAgent | `~/Library/LaunchAgents/com.marmotim.asr.plist` |
| 服务日志 | `~/Library/Logs/MarmotIM/asr-server.{out,err}.log` |

它**不碰**你的系统 `python3`（`tools/build_dictionary.py` 照常用原来那个跑）、
不碰用户词库与设置、不碰 iCloud 数据。

### 2.2 确认装好了

```bash
launchctl list | grep com.marmotim.asr
curl -s http://127.0.0.1:58471/health
```

第二条应该返回类似：

```json
{"status":"ready","model":"mlx-community/Qwen3-ASR-1.7B-bf16","model_loaded":true,"version":"1","detail":null}
```

`"status":"loading"` 表示服务活着但模型还在读权重 —— 这是正常的，等一会儿再看。
刚开机或刚切换模型时都会经过这个状态，加载完成前转写会失败并提示「模型加载中，稍后再试」。

### 2.3 打开开关

「设置 → 转写 → 启用语音转写」。**默认是关的**，这是刻意的：没开的时候，
转写这条路完全不联网，也不会去碰麦克风。

### 2.4 授权麦克风

第一次真正开始录音时，系统会自己弹窗问你要不要给麦克风权限。设置页「麦克风」一栏
显示当前状态：

- **尚未授权** —— 旁边有「请求授权」按钮，点它会弹系统窗；
- **已授权** —— 可以用了；
- **已拒绝** —— 系统**不会再问第二次**。点「打开系统设置」，到
  「隐私与安全性 › 麦克风」里手动勾上土拨鼠输入法。

## 3. 怎么用

**按住右 Command 键，说话，松开。**

1. 按住右 ⌘ 超过约 250 毫秒（避免误触），屏幕上出现 `🎤 录音中`；
2. 说话；
3. 松开，提示变成 `转写中…`；
4. 识别完成，文字插到光标处，提示消失。

几条你应该知道的行为：

- **左 Command 完全不受影响。** 程序区分左右两个键靠的是键码，左 ⌘ 的一切快捷键照旧。
- **右 ⌘ 也还是能当修饰键用。** 事件监听是只读的（不吞事件、不改写事件），
  所以用右手拇指按住 ⌘ 再敲 C 照样是复制。长按期间只要**另一个修饰键**跳变，
  本次长按立刻作废、不会插字。
- **土拨鼠不是当前输入源时，长按什么也不做。** 不录音、不发请求、不显示提示 ——
  连麦克风指示灯都不会亮。这是刻意的，不是没做完。
- **太短的按压会被静默丢弃。** 快按一下不足 250 ms 根本不会开始录音；
  录到的音频短于下限也会被直接丢掉，不会弹错误。
- **快捷键暂不支持自定义。**

## 4. 设置页逐项说明

「设置 → 转写」。分五块，前四块常显，最后一块默认折叠。

### 语音转写

| 项 | 默认 | 说明 |
|---|---|---|
| 启用语音转写 | 关 | 总开关。关闭时不联网、不占麦克风 |
| 快捷键 | 按住右 Command 键 | 只读展示，暂不可改 |

### 服务状态

一个指示灯加一个「检查」按钮。**这一页没有定时器** —— 只在窗口打开时和你点「检查」时各探一次，
不会在后台反复打请求。

| 显示 | 含义 | 该怎么办 |
|---|---|---|
| 尚未检查 | 还没探过（刚打开窗口的一瞬间） | 等一下，或点「检查」 |
| 未安装 | 那个地址/端口上没有服务在听 | 跑 `bash scripts/install_asr.sh` |
| 启动中 | 服务活着，模型在加载 | 等十几秒再检查 |
| 正常 | 可以用了，下面一行显示当前加载的模型 | — |
| 异常 | 服务自己报告了故障，原文照抄显示 | 看那行红字，再看服务日志（§5.5） |

### 麦克风

权限三态与按钮，见 §2.4。

### 识别

| 项 | 默认 | 说明 |
|---|---|---|
| 语言 | 自动检测 | 可锁定为「中文」或「English」。**自动检测**时请求里根本不带语言字段，由模型自己判断 |
| 热词 | 空 | 空格分隔的专有名词，例如 `土拨鼠 五笔 仓颉` |

关于热词，有一句必须说清楚：**热词只是引导，不能强制改写结果，而且填错会帮倒忙** ——
一串不相干的热词能把模型本来认对的词带偏。只填你确实常说的专有名词，宁缺毋滥。

细节：

- 除了这个框，输入法还会自动带上你用户词库里 frecency 最高的一批词；
- 两者合起来有 200 字符的预算，装不下时**先砍自动带上的那批** —— 你手填的是明确指令，
  自动补的只是猜测，猜测不该把指令挤掉；
- 分隔符除了空格，中文逗号、顿号、分号、`/`、`|` 都算，所以顺手打成「土拨鼠，五笔」也切得开。

### 高级（默认折叠）

绝大多数人一辈子不需要动这里任何一项。所有数值框都是**输入非法就当场退回**：
红字提示，你敲的内容原样留在框里，配置一个字节都不会被改写 —— 不会出现「填了 70000
被悄悄改成 65535」这种事。

| 项 | 默认 | 允许范围 | 说明 |
|---|---|---|---|
| 主机 | `127.0.0.1` | 仅 `127.0.0.1` / `localhost` / `::1` | 不开放局域网，填别的会被退回 |
| 端口 | `58471` | 1024–65535 | 1024 以下是特权端口 |
| 模型 | 1.7B（更准，默认） | 1.7B / 0.6B（更快） | 切换后服务要重新加载权重，期间状态显示「启动中」 |
| 请求超时 | 15 秒 | 1–120 秒 | 超时只放弃这一次结果，不会自动重试 |
| 录音上限 | 120 秒 | 5–600 秒 | **修饰键卡住时的保险丝，不是说话时长上限**；触发时会把已采到的部分交出去转写 |
| 按住阈值 | 250 毫秒 | 50–2000 毫秒 | 按住右 ⌘ 超过这个时长才开始录音 |
| 去掉句尾标点 | 开 | — | 只去掉结果**末尾的一个**「。」「，」或「.」，句中标点原样保留 |

## 5. 出问题了怎么办

### 5.1 提示「转写服务未运行」

服务没起来。依次试：

```bash
launchctl list | grep com.marmotim.asr      # 有输出说明 agent 装了
curl -s http://127.0.0.1:58471/health       # 有输出说明它真的在听
bash scripts/install_asr.sh                 # 重新对齐（幂等，安全）
launchctl kickstart -k gui/$UID/com.marmotim.asr   # 强制重启服务
```

### 5.2 提示「模型加载中，稍后再试」

服务在，权重还没读完。这时**不会自动重试** —— 你正站着等，静默重试只会把等待时间翻倍，
自己再按一次更快。等状态变成「正常」再说。

### 5.3 麦克风被拒绝了

系统只问一次。到「系统设置 › 隐私与安全性 › 麦克风」里手动勾上土拨鼠输入法，
或在设置页点「打开系统设置」。改完回设置页，重开窗口会重新读一次状态。

### 5.4 模型没装 / 想换一个

权重不在缓存里时，`install_asr.sh` 会先查磁盘空间再下载（默认模型约 4.1 GB，
可能要十几分钟到一个多小时）。下载中断了直接重跑，它会续传。想彻底重下，
先删掉 `~/.cache/huggingface/hub/` 下对应模型的目录。

### 5.5 看服务自己怎么说

```bash
tail -50 ~/Library/Logs/MarmotIM/asr-server.err.log   # 启动与推理错误都在这
tail -50 ~/Library/Logs/MarmotIM/asr-server.out.log
launchctl print gui/$UID/com.marmotim.asr | head -20  # 进程状态、退出码
```

### 5.6 提示「转写超时」

服务端可能还在解码。超时只是我们放弃了这一次的结果（不重试、提示立刻收掉）。
经常发生的话，换 0.6B 模型，或把「请求超时」调大。

### 5.7 想卸载

```bash
bash scripts/install_asr.sh --uninstall   # 只卸 LaunchAgent，虚拟环境和权重留着
```

要腾磁盘，再手动删 `~/Library/Application Support/MarmotIM/asr/` 和 `~/.cache/huggingface/hub/` 下的模型目录。
或者干脆在设置里把开关关掉 —— 关掉之后它就是一个不跑的后台服务，对打字毫无影响。

## 6. 几个「为什么没有」

这些不是没做完，是查证之后确定不做的。

**为什么没有流式（边说边出字）？**
Qwen3-ASR 的流式模式只在 vLLM 后端上存在，而 vLLM 在 Apple Silicon 上跑不了 MLX 的模型 ——
在这台机器上它根本不可达。与其在设置里放一个按下去什么也不会发生的开关，不如不放。
所以这里是「说完再出字」，不是「边说边出字」。

**为什么没有分块（chunk）设置？**
底层库的分块阈值默认是 1200 秒（20 分钟），而一次录音最多 120 秒就被保险丝掐断了 ——
分块路径在正常使用中永远走不到。暴露一个永远不生效的旋钮只会让人以为它有用。

**为什么没有说话人分离（diarization）？**
所用的库里压根没有这部分代码，也没有相关依赖。不是关掉了，是不存在。

**为什么右 Command 长按期间敲字母不会取消？**
系统只在**修饰键**变化时给我们事件。要拿到普通按键的事件就得申请「辅助功能」权限，
而听写不值得为此多要一项系统授权。折中方案是：任何其他修饰键跳变都作废本次长按；
剩下「按住右 ⌘ 再敲字母」的情形只会多出一段几乎无声的录音，被最短时长和空结果两道兜底吃掉。

**为什么「最大生成长度」不在设置里？**
它交给底层库自动计算（按音频时长算，短句给 256，长句自动增长）。写死一个数会把超过
几秒的句子直接截断。这一项在早期计划里曾列入高级区，最终**没有提供** —— 一个只会把
事情弄坏的旋钮不如没有。
